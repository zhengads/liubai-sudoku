# 留白 · 数独

在方寸之间，找回专注。

**[点击在线游玩](https://zhengads.github.io/liubai-sudoku/)**

一个原生 HTML、CSS 和 JavaScript 编写的数独网页游戏，适配手机与电脑，无运行时第三方依赖。

## 游戏功能

- 6×6、9×9、16×16 三种棋盘，每种棋盘包含轻松、适中、挑战三个难度；每组 120 关，共 1080 关，使用全局唯一编号。
- 可收起的数字键盘、淡色铅笔草稿、擦除与撤销，也支持实体键盘。
- 题目数字与填写数字使用不同颜色和字形；重复填写只标红格子背景。
- 讲解式提示：展示排除过程与唯一位置；无法确定时提供候选数，可记入草稿，不直接代填答案。
- 入口页可继续上关、重新开始或打开关卡目录；每关独立保存数字、草稿和计时。
- 默认全览，支持 100%–300% 缩放；完成后显示用时、提示次数，并可进入下一关。
- 浏览器本地合成轻音乐：独立开场旋律与多组关卡变奏，切换时渐变衔接，采用较柔和的中低音区。

难度目前按留空数量区分，不代表严格的解题技巧等级。所有编号题目都会在测试中检查唯一解。

## 操作

轻点空格即可展开数字键盘。“草稿”可记录多个候选数，再点同一数字可取消。

| 按键                         | 操作                      |
| ---------------------------- | ------------------------- |
| `1`–`9`                      | 填写数字                  |
| `A`–`G`                      | 在 16×16 棋盘中填写 10–16 |
| 方向键                       | 移动选中格                |
| `N`                          | 切换草稿                  |
| `Backspace` / `Delete` / `0` | 擦除                      |
| `Ctrl` / `⌘` + `Z`           | 撤销                      |
| `Esc`                        | 收起键盘或缩放控件        |

音乐每次打开页面或从入口进入游戏时默认开启，关闭状态只在本次有效，不写入存储。若浏览器限制自动播放，轻触开场的“轻触进入”即可同步启动音乐与动画，无需反复操作音乐开关。

## 本地开发

需要 Node.js 22 或更新版本。

```bash
npm ci
npm start
```

打开 <http://127.0.0.1:4173/>。修改 `src/` 后执行 `npm run build`，然后刷新页面。

```bash
npm test              # 数独、存档与音频调度测试
npm run format:check  # 检查代码格式
npm run format        # 格式化源码
npm run build         # 输出静态站点与离线单文件
```

构建生成的 `dist/play.html` 及根目录的 `留白数独.html` 均包含所需样式、图标和脚本，可下载后离线使用。通过 `?qa=1` 打开页面可使用临时内存存档，刷新即清空，方便验收时避免污染正式进度。

## 代码结构

```text
src/
  index.html    页面结构与入口
  style.css     视觉样式、适配与动画
  app.js        游戏交互、关卡目录与页面状态
  engine.js     出题、求解、候选数、冲突检测与逻辑提示
  progress.js   分关存档与关卡编号
  music.js      浏览器音频合成、变奏与播放解锁
  icon.svg      网页图标
scripts/
  build.cjs     静态资源复制与单文件打包
  serve.cjs     本地静态预览服务器
test/           使用 Node.js 内置测试框架的回归测试
.github/workflows/pages.yml  检查并部署 GitHub Pages
```

`dist/` 是构建产物；本地验收截图和备份位于 `.local/`，均不会提交到仓库。

## 存档与发布

游戏进度仅保存在当前浏览器的 `localStorage`，不上传服务器。清理浏览器数据、切换设备、浏览器或网站域名后，原进度不会自动同步。在线版与本地预览也分别保存进度。

推送到 `main` 后，GitHub Actions 会检查格式、运行测试、构建静态文件，并部署 GitHub Pages。仓库的 **Settings → Pages → Source** 使用 **GitHub Actions**；这是 GitHub 支持的[自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
